- The fix is a single token change: `sourceType: source` → `sourceType: collection` in `processWebhookEvent` in `handler.ts`. No other files change.
- `fast-check` must be added as a dev dependency before running the PBT tasks (`npm install --save-dev fast-check` from the `infra/` directory).
- The exploration test (task 1) is intentionally written to FAIL on unfixed code. This is correct and expected — the failure is the proof the bug exists.
- The preservation tests (task 2) must PASS on unfixed code before the fix is applied — they establish the behavioral baseline.
- Run tests with `--no-coverage` to avoid slow coverage collection during development iteration.
- Test files live alongside source in `infra/lambda/ingestion/` per the Jest `roots` config in `infra/jest.config.js`.
